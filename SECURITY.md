# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub: **Security → Report a vulnerability** in this repository
([private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).
Include what you found, how to reproduce it and which version (`git` tag or image digest) is affected.

You get a first answer within a week. Fixes are released as a new version; the advisory is published once an update is
available.

## Supported versions

Only the latest release receives security fixes.
