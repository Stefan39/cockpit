# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it and which version (release tag or image digest) is affected. You will get an
acknowledgement within 72 hours and a fix or mitigation plan within 14 days for confirmed issues. Credit is given in the
release notes unless you prefer otherwise.
